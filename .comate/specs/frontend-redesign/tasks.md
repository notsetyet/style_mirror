# StyleMirror 前端重构任务清单

## 任务概览
本次任务将彻底重写 `app.py` 的渲染逻辑，实现小红书风格的视觉体验，共 5 个任务。

---

## 具体任务列表

- [x] Task 1: CSS 注入与全局样式定义
    - 1.1: 创建 `inject_xhs_styles()` 函数，注入小红书风格 CSS
    - 1.2: 定义全局主色调 (--xhs-red: #FF2442)
    - 1.3: 定义圆角容器样式 (border-radius: 15px, box-shadow)
    - 1.4: 定义字体样式（系统无衬线字体，字间距收缩）

- [x] Task 2: 核心组件开发
    - 2.1: 开发 `render_color_lab()` 色彩实验室组件（30px 圆形色块）
    - 2.2: 开发 `render_scene_tags()` 场景标签组件（胶囊形状）
    - 2.3: 开发 `typewriter_effect()` 打字机效果函数
    - 2.4: 色块支持点击复制色号功能

- [x] Task 3: 侧边栏重构
    - 3.1: 收纳 API Key 输入框（password 类型）
    - 3.2: 收纳 Base URL 输入框
    - 3.3: 添加配置状态指示器
    - 4.4: 保持侧边栏简洁美观

- [x] Task 4: 主界面布局重构
    - 4.1: 左侧：上传区 + 原图预览
    - 4.2: 左侧：AI 视觉感知区（风格标签 + 色块 + 场景词）
    - 4.3: 右侧：点点对话区（带头像）
    - 4.4: 右侧：单品推荐瀑布流卡片

- [x] Task 5: 点点 Agent 对话区
    - 5.1: 设计点点头像（渐变色圆形）
    - 5.2: 实现对话气泡样式
    - 5.3: 集成打字机效果输出 description
    - 5.4: 添加 Agent 状态指示

---

## 执行顺序说明
1. **Task 1** 先执行，定义全局样式
2. **Task 2** 执行核心组件开发
3. **Task 3-4** 并行执行，重构布局
4. **Task 5** 最后执行，完善 Agent 对话区
